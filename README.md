# MapleCompanion

A zero-ongoing-cost, mobile-first MapleStory Classic World companion website and PWA.

## Vision
Help players make better decisions by combining market data, item/monster drops, quest rewards, training economics, character lookup, and upgrade calculators.

## Planned features
- **Market Sniper:** spot genuinely underpriced, liquid Free Market listings with source and scan timestamps.
- **Drops & Hunt:** find monster drops and calculate expected profit and EXP.
- **Quests:** filter by character level and rank rewards by practical value.
- **Character lookup:** public ranking search where an authorized API is available, with manual fallback.
- **Portfolio & calculators:** track trades, scroll odds and consumable efficiency.
