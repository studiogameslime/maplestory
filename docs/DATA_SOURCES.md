# Source feasibility and access evidence

Technical verification on **November 10, 2026 UTC** used anonymous HTTP requests, documented JSON downloads and public license or policy pages. No paid account, API token, browser-challenge workaround or continuous collector was used. A policy-page response is recorded as such. A retrieval timestamp describes the audit, while a source revision or game build identifies the evidence behind a claim. [Data model](DATA_MODEL.md)

### MapleClassic Wiki · mapleclassic.wiki

This is a separate publisher and an upstream contributor to Classic Maple Wiki. It licenses original contributions and Cargo data under CC BY-NC-SA 4.0. Limited, page-attributed, noncommercial public adaptations and local storage are permitted. The publisher requests that consumers avoid wholesale table copying. It excludes Nexon audiovisual assets and substantial in-game writing. Its robots file excludes special pages, index.php query paths and the player-reports REST route. The selected MediaWiki revision API route is outside those exclusions. No numerical quota or fixed publication interval was established. The About policy revision was last edited Nov 5. [License and reuse requests](https://mapleclassic.wiki/wiki/MapleWiki:About#Reusing_the_wiki) · [Robots](https://mapleclassic.wiki/robots.txt)

A single revision query returned HTTP 200 for the 24 pinned pages in the supplement. The importer extracts selected facts, requirements, rewards and quantities, costs, compatibility and two recipes. It discards the article text and image references. The revision API's actual response shape includes `query.pages[].revisions[].{revid,timestamp,slots}`. For example, revision 89507 links Green Mushroom Cap ×15 to quest 10211, with Bronze Ore ×5 as a reward in version 1.0.0. Arturo's shop lists Red Potion at 50 mesos per unit in 0.9.0. The Red Potion page lists a 5-meso NPC buyback in 1.0.0. Each price stays attached to its own version and direction. The supplement includes pets and a five-slot pet equipment item. [Testable revision request](https://mapleclassic.wiki/api.php?action=query&prop=revisions&revids=89507&rvprop=ids%7Ctimestamp%7Ccontent&rvslots=main&format=json&formatversion=2) · [Pinned supplementary sources](SUPPLEMENT.md)

## Drop evidence

The Axe Stump → Firewood community row records **17 drops in 37 kills**, Founder's Access, observed October 11. The exported rate is 45.95%. Sample size, observation date, build and source travel with the relationship. A binomial interval assumes independent kills under comparable drop conditions. Multiple items per drop, drop buffs, player selection and changes between builds can violate those assumptions. An NPC price or a beta rate cannot silently substitute for a current net market value or current drop chance. No official server-side drop probability feed was established in this investigation. Unknown rates stay unknown. [Axe Stump](https://mapleclassic.wiki/wiki/Axe_Stump) · [Drop reports and testing](https://mapleclassic.wiki/wiki/MapleWiki:Report_an_item_drop)

## Character lookup

The free keyless Windia API permits single-name GET requests with visible ClassicRank attribution. Limit 30 requests/minute/IP. Responses have a 30-second server cache and 429 carries Retry-After. List ranking positions refresh each minute. Character observations are updated when a scanner or player submission supplies evidence. The free API supports fame, job, level, rank, observation and level-change times, plus photo/profile URLs. It cannot guarantee an immediate level update. The project performs user-initiated lookups. Permanent mirroring and image redistribution rights were not established. Its robots excludes API crawling. [Developer reference](https://classicrank.com/developer) · [Robots](https://classicrank.com/robots.txt) · [Privacy](https://classicrank.com/privacy)

## Cost envelope

Cloudflare Pages Free allows one concurrent build, 500 builds/month, 20 minutes per build, 20,000 files per site and 25 MiB per asset. Commit the static snapshot, build once per code/data change and serve the atlas through static assets. Split future snapshots before a file reaches the size limit. No paid tier, custom domain, Functions, database or storage binding is needed. GitHub's standard hosted runners are free for public repositories. The existing workflow uses a standard Ubuntu runner. Avoid larger paid runners and private-repo overages. The source refresh can run manually. No scheduled paid scanning is part of this proof.
